<Steps>
 <Step title="Creating a Request" stepNumber="1">
   To query registration data by CPF, CNPJ, or Name, the request must be made through the `/requests/create` endpoint of the lawsuits API. The registration data query can be performed directly against our datalake or in real time against the Federal Revenue Service (Receita Federal). To run the query in real time, simply add the `on-demand` parameter with the value `true` to the request payload.

    <Note>
    For the registration data query, `search_type` must be <strong>'cpf'</strong>, <strong>'cnpj'</strong>, or <strong>'name'</strong>, and the `response_type` field must always be <strong>'entity'</strong>.
    </Note>

   **Example query by CPF:**

   ```bash
   curl --location 'https://lawsuits.prod.judit.io/requests/create' \
    --header 'Content-Type: application/json' \
    --header 'api-key: <API-KEY>' \
    --data '{
        "search": {
            "search_type": "cpf",
            "search_key": "999.999.999-99",
            "response_type": "entity"
	    }
    }'
    ```

    **Example query by CNPJ:**

    ```bash
   curl --location 'https://lawsuits.prod.judit.io/requests/create' \
    --header 'Content-Type: application/json' \
    --header 'api-key: <API-KEY>' \
    --data '{
        "search": {
            "search_type": "cnpj",
            "search_key": "99.999.999/9999-99",
            "response_type": "entity"
	    }
    }'
    ```

    **Example query by Name:**

    <Warning>
    When running name-based registration data queries, there may be namesakes (people or companies sharing the same name). Whenever possible, we recommend using unique identifiers such as CPF or CNPJ to ensure greater accuracy of the results.
    </Warning>

   ```bash
   curl --location 'https://lawsuits.prod.judit.io/requests/create' \
    --header 'Content-Type: application/json' \
    --header 'api-key: <API-KEY>' \
    --data '{
        "search": {
            "search_type": "name",
            "search_key": "Nome teste",
            "response_type": "entity"
	    }
    }'
    ```

    <Note>
    When running a CNPJ query, you can obtain detailed information, including unmasked data of the partners associated with the queried CNPJ. To access this information, include the `reveal_partners_documents` property and set its value to `true`.
    </Note>
