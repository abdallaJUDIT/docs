## How the prompt works

The prompt points to the [Judit skill](https://docs.judit.io/skill.md), a playbook written for AIs. After reading it, the AI:

- **Interviews you before writing code** — what you want to solve, your business rule, volume and frequency — and proposes an API usage plan.
- **Reads only the pages it needs** from the documentation, always the current version (the docs are living).
- **Warns you and asks for confirmation** before potentially high-cost actions (on-demand queries, tracking, batches, attachments) and suggests how to use them efficiently.
- **Protects your `api-key`**: it always stays on the server, never in the frontend.
- **Helps you troubleshoot** and, if needed, drafts a complete support ticket.

The skill is written in Portuguese; the AI talks to you in your own language.

## Install the MCP server

The documentation MCP server delivers the same skill (`judit-api`) and the `search_judit_docs` and `query_docs_filesystem_judit_docs` tools, which the AI uses to search and read the docs without copy-pasting.

<Card title="MCP server URL" icon="link" href="https://docs.judit.io/mcp">
  `https://docs.judit.io/mcp`
</Card>

With the MCP server connected, use this prompt — it points to the skill delivered by the MCP server itself (the `judit-api` resource), with no web access needed:

## What it does not do

The MCP server and the prompt **only read the documentation**: they don't call the Judit API for you and don't generate costs. Real calls are made by the code the AI writes, with your `api-key` on the server — or via the [Postman Collection](/en/resource/postman-collection).
