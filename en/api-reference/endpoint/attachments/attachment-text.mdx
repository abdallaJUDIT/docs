---
title: "Download attachment text (OCR)"
description: "Downloads the OCR-extracted text of a lawsuit attachment."
openapi: "openapi/requests.json GET /responses/{response_id}/attachments/{attachment_id}/text"
api: "GET https://requests.production.judit.io/responses/{response_id}/attachments/{attachment_id}/text"
icon: "file-lines"
---

<Warning>
**Beta, available only to some customers.** To enable attachment OCR on your account, contact support at [atendimento@judit.io](mailto:atendimento@judit.io).
</Warning>

The route returns the `attachment_text_url` field with the download link for the attachment's extracted text (UTF-8).

For the text to be available, the request must have been created with `search_params.with_attachments_ocr: true`. While the text has not been extracted yet, the route responds `404`.

<Info>
The text file is served with `Content-Encoding: gzip`. Browsers and HTTP clients such as fetch, axios and requests decompress it automatically. With curl, use `--compressed`.
</Info>
