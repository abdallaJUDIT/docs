---
title: "Download lawsuit attachment"
description: "Downloads an attachment from a lawsuit returned in a response."
openapi: "openapi/requests.json GET /responses/{response_id}/attachments/{attachment_id}"
api: "GET https://requests.production.judit.io/responses/{response_id}/attachments/{attachment_id}"
icon: "paperclip"
---

The attachment is downloaded from the **response** (`response_id`) that contains the lawsuit. The route returns the `attachment_url` field with the file's download link.

For the attachment to be available:

1. Create the request with `"with_attachments": true`.
2. Fetch the responses at `GET /responses?request_id=<request_id>` and take the lawsuit's `response_id`.
3. In the lawsuit's `attachments` array, use the `attachment_id` of an attachment with `status: "done"`.

<Note>
Need every attachment of the lawsuit in a single file? See [Download consolidated attachments](/en/api-reference/endpoint/attachments/attachment-consolidated).
</Note>

## Errors

| HTTP | `error.name` | `error.message` | When it happens |
| :--- | :--- | :--- | :--- |
| `401` | `HttpUnauthorizedError` | `UNAUTHORIZED` | The `api-key` header is missing or the key is invalid. |
| `403` | `HttpForbiddenError` | `FORBIDDEN` | The key is valid but is not allowed to access the resource. |
| `500` | `HttpInternalServerError` | `INTERNAL_SERVER_ERROR` | Internal Judit error. Retry and, if it persists, contact support at [atendimento@judit.io](mailto:atendimento@judit.io). |

Every error uses the same envelope. The specific code is in `error.data`:

```json
{
  "error": {
    "name": "HttpUnauthorizedError",
    "message": "UNAUTHORIZED",
    "data": "MISSING_AUTHORIZATION"
  }
}
```

See the list of `error.data` codes in [API errors](/en/resource/errors).
