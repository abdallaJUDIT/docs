## Overview

The **Judit API** is a complete solution for automating judicial queries in Brazil, providing programmatic access to lawsuit data, lawsuit tracking, and court credential management.

### What is the Judit API?

The Judit API lets developers integrate judicial query features into their applications, offering:

- **Queries by CPF, CNPJ, OAB, NAME, or CNJ**: Search for lawsuits using different types of identifiers
- **Automated tracking**: Follow changes in specific lawsuits
- **Attachment access**: Download case documents and attachments
- **Registration data**: Obtain registration information for individuals and companies
- **Credential management**: Store and manage court credentials securely
- **Arrest warrant queries**: Access arrest warrants with precision and relevance of information.
- **Penal execution queries**: Obtain accurate and relevant data on penal execution cases, ensuring fast access to essential information.
- **JUDIT AI**: Feature that automatically generates a summary of the lawsuit header, highlighting the main information clearly and quickly.

### API Architecture

The Judit API is composed of different specialized services:

- **Requests Service** (`requests.prod.judit.io`): Creation and lookup of requests
- **Lawsuits Service** (`lawsuits.production.judit.io`): Access to the lawsuits datalake
- **Tracking Service** (`tracking.prod.judit.io`): Lawsuit tracking

### Rate Limits

- **Default limit**: 500 requests per minute
- **Monitoring**: Rate limit headers in every response
- **Upgrade**: Custom limits available under contract
