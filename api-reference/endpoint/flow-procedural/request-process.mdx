<Steps>
 <Step title="Criação da Request" stepNumber="1">
  Para realizar a consulta processual, é necessário criar uma requisição do tipo POST para o endpoint <code>/requests</code> passando o search_type e o search_key no corpo da requisição:

  ```bash
  curl --request POST
    --url https://requests.prod.judit.io/requests
    --header 'Content-Type: application/json'
    --header 'api_key: SUA-API-KEY'
    --data '{
      "search": {
       "search_type": "lawsuit_cnj",
       "search_key": "0817064-37.2023.8.19.0209"
      }
   }'
  ```

  A resposta dessa requisição será um objeto JSON com os dados de criação da Request:

  ```json
  {
    "request_id": "cb97f8ba-7736-43c7-a961-436b151cd65c",
    "search": {
      "search_type": "lawsuit_cnj",
      "search_key": "0817064-37.2023.8.19.0209",
      "response_type": "lawsuit",
      "search_params": {
        "filter": {},
        "pagination": {}
      }
    },
    "origin": "api",
    "origin_id": "ad070209-2523-4808-b2e4-c1571e6fc82b",
    "user_id": "82082593-c664-4d7b-b174-2f0dc4791daf",
    "status": "pending",
    "created_at": "2024-02-21T17:15:02.700Z",
    "updated_at": "2024-02-21T17:15:02.700Z",
    "tags": {}
  }
  ```

  <Note>
  Na consulta processual o <strong>search_type</strong> corresponde ao número do processo.
 </Note>

  Outros parâmetros que podem ser adicionados na requisição, como filtros, podem ser
  encontrados na página:

  <a href="https://docs.judit.io/api-reference/endpoint/requests/create">
   https://docs.judit.io/api-reference/endpoint/requests/create
  </a>
 </Step>
 <Step title="Consultar o status da request (opcional)">
  ```bash
  curl --request GET
    --url https://requests.prod.judit.io/requests/cb97f8ba-7736-43c7-a961-436b151cd65c
    --header 'Content-Type: application/json'
    --header 'api_key: SUA-API-KEY'
  ```

 Resposta:

  ```json
  {
    "request_id": "cb97f8ba-7736-43c7-a961-436b151cd65c",
    "search": {
      "search_type": "lawsuit_cnj",
      "search_key": "0817064-37.2023.8.19.0209",
      "response_type": "lawsuit",
      "search_params": {
        "filter": {},
        "pagination": {}
      }
    },
    "origin": "api",
    "origin_id": "ad070209-2523-4808-b2e4-c1571e6fc82b",
    "user_id": "82082593-c664-4d7b-b174-2f0dc4791daf",

    }
  }
  ```

  Através da propriedade <strong>status</strong> é possível saber se a requisição está completa.
 </Step>

 <Step title="Consultar o conteúdo da resposta" stepNumber="3">
  Na URL vai o <strong>request_id</strong> retornado na primeira requisição.
  ```bash
  curl --request GET
    --url https://requests.prod.judit.io/responses/?request_id=cb97f8ba-7736-43c7-a961-436b151cd65c
    --header 'api_key: SUA-API-KEY'
    --header 'Content-Type: application/json'
  ```
