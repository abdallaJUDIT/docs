<Note>
Esta rota faz parte do fluxo de [exportação ZIP de anexos](/api-reference/endpoint/attachments/attachment-export-create), que não está disponível para todos os clientes.
</Note>

Quando a exportação está `completed`, a rota responde `307` e redireciona para a URL pré-assinada do ZIP. Configure seu cliente HTTP para seguir redirecionamentos. Com curl, use `--location`:

```bash cURL
curl --location 'https://requests.production.judit.io/responses/<response_id>/attachments/exports/<attachments_export_id>/download' \
--header 'api-key: <api-key>' \
--output anexos.zip
```
