---

<Note>
Esta rota faz parte do fluxo de [exportação ZIP de anexos](/api-reference/endpoint/attachments/attachment-export-create), que requer liberação na conta.
</Note>

| `status` | Significado |
| :--- | :--- |
| `pending` | A exportação está na fila. |
| `processing` | O ZIP está sendo gerado. Acompanhe `exported_attachments` em relação a `total_attachments`. |
| `completed` | O ZIP está pronto. A resposta traz `attachments_zip_url`, válido até `expires_at`. |
| `failed` | A exportação falhou. O motivo vem no campo `error`. |
