<ParamField body="credentials" type="array" required={false}>
  <Expandable title="properties">
    <ParamField body="system_name" type="string" required>
      PJE TJBA - 1º grau ou * (coringa)
    </ParamField>

    <ParamField body="customer_key" type="string" required>
      00000001 (utilizar a sua forma de identificar um cliente)
    </ParamField>

    <ParamField body="username" type="string" required>
      999.999.999-99 (cpf)
    </ParamField>

    <ParamField body="password" type="string" required>
      Senha123
    </ParamField>
  </Expandable>
</ParamField>

<Accordion title="Observação criteriosa sobre o cadastro de credencial">
`Credencial Coringa`: *

Se cadastrar alguma credencial nela, todos os tribunais que não tenham uma outra credencial cadastrada, irão utilizar a credencial coringa.

Caso não seja informada nenhuma `customer_key`, será criada uma `customer_key` vazia.
</Accordion>

Caso queira excluir a credencial de algum system, deverá passar o `username` e `password` como vazio.
