---
title: "Cadastro de Credenciais"
openapi: "openapi/vault.json POST /credentials"
api: "POST https://crawler.prod.judit.io/credentials"
description: "Cadastre ou atualize credenciais de usuário e senha (com segredo 2FA opcional) para um ou mais sistemas de tribunal."
icon: "key"
---

<Info>
Antes de cadastrar, identifique no portal do tribunal o que ele pede para o login: senha, código de aplicativo autenticador ou certificado digital. Veja [Passo 1: identifique como o tribunal faz o login](/essentials/cofre-de-credenciais#passo-1-identifique-como-o-tribunal-faz-o-login).
</Info>

<ParamField body="credentials" type="array" required>
Lista de credenciais a cadastrar.
    <Expandable title="properties">
        <ParamField body="system_name" type="string" required>
        Nome do sistema e tribunal, **exatamente** como aparece em `GET /credentials` — por exemplo `PJE TJBA - 1º grau`. Use `*` para a credencial coringa.
        </ParamField>

        <ParamField body="customer_key" type="string">
        Identificador que você define para a credencial (por advogado, cliente ou escritório). Se omitido, é usado o valor padrão `*`.
        </ParamField>

        <ParamField body="username" type="string" required>
        Login usado no portal do tribunal: CPF ou número da OAB, conforme o tribunal exige.
        </ParamField>

        <ParamField body="password" type="string" required>
        Senha usada no portal do tribunal.
        </ParamField>

        <ParamField body="custom_data" type="object">
        Envie apenas quando o tribunal pede código de aplicativo autenticador.
            <Expandable title="properties">
                <ParamField body="secret" type="string">
                Segredo 2FA — a **chave fixa** de configuração do aplicativo autenticador, nunca o código temporário de 6 dígitos. A Judit gera o código a cada login.
                </ParamField>
            </Expandable>
        </ParamField>
    </Expandable>
</ParamField>

<RequestExample>
```bash cURL
curl --location 'https://crawler.prod.judit.io/credentials' \
--header 'api-key: <api-key>' \
--header 'Content-Type: application/json' \
--data '{
  "credentials": [
    {
      "system_name": "PJE TJBA - 1º grau",
      "customer_key": "advogado_01",
      "username": "999.999.999-99",
      "password": "<senha-do-tribunal>"
    }
  ]
}'
```

```bash cURL com 2FA
curl --location 'https://crawler.prod.judit.io/credentials' \
--header 'api-key: <api-key>' \
--header 'Content-Type: application/json' \
--data '{
  "credentials": [
    {
      "system_name": "PJE TJBA - 1º grau",
      "customer_key": "advogado_01",
      "username": "999.999.999-99",
      "password": "<senha-do-tribunal>",
      "custom_data": {
        "secret": "JBSWY3DPEHPK3PXP"
      }
    }
  ]
}'
```
</RequestExample>

<ResponseExample>
```json
[
	{
		"system_name": "PJE TJBA - 1º grau",
		"message": "CREDENTIAL_CREATED"
	}
]
```
</ResponseExample>

<Warning>
Com um body válido (a lista `credentials`), esta rota responde **HTTP 200** mesmo quando um item não é cadastrado. Confira o `message` de cada item da resposta. Um body inválido, sem a lista `credentials`, retorna HTTP 400.
</Warning>

<Accordion title="Valores de message">
| `message` | Quando acontece |
| :--- | :--- |
| `CREDENTIAL_CREATED` | Credencial cadastrada. |
| `CREDENTIAL_UPDATED` | Já existia credencial com o mesmo `system_name` e `customer_key`; ela foi substituída, inclusive o `custom_data`. |
| `SYSTEM_NAME_NOT_FOUND` | `system_name` vazio ou inexistente no Cofre. |
| `USERNAME_NOT_FOUND` | `username` ausente ou vazio. |
| `PASSWORD_NOT_FOUND` | `password` ausente ou vazio. |
| `USERNAME_AND_PASSWORD_NOT_FOUND` | `username` e `password` ausentes. |
| `CERTIFICATE_FIELDS_NOT_ALLOWED` | Campos de certificado enviados em `custom_data`. |
</Accordion>

<Note>
Certificado digital não é aceito nesta rota: um campo `file_base64` é ignorado sem erro. Use [Cadastro de Certificado Digital](/api-reference/endpoint/vault/vaultcertificate). Para remover uma credencial, use [Remoção de Credencial](/api-reference/endpoint/vault/vaultdelete).
</Note>
