---
title: "Remoção de Credencial"
openapi: "openapi/vault.json DELETE /credentials"
api: "DELETE https://crawler.prod.judit.io/credentials"
description: "Remova a credencial de um sistema para uma customer_key. Para a credencial coringa ou um certificado, use system_name \"*\"."
icon: "trash"
---

<ParamField body="system_name" type="string" required>
Sistema da credencial, exatamente como foi cadastrado. Para a credencial coringa ou para um certificado digital, use `*`.
</ParamField>

<ParamField body="customer_key" type="string">
`customer_key` da credencial. Se omitido, é usado o valor padrão `*`.
</ParamField>

<RequestExample>
```bash cURL
curl --location --request DELETE 'https://crawler.prod.judit.io/credentials' \
--header 'api-key: <api-key>' \
--header 'Content-Type: application/json' \
--data '{
  "system_name": "PROJUDI TJGO - 1º grau",
  "customer_key": "advogado_01"
}'
```
</RequestExample>

<ResponseExample>
```json
{}
```
</ResponseExample>

<Accordion title="Erros possíveis">
| Código | HTTP | Quando acontece |
| :--- | :--- | :--- |
| Erro de validação | 400 | `system_name` ausente. |
| `SOURCE_NOT_FOUND` | 404 | O `system_name` não corresponde a nenhum sistema do Cofre. |
| `CREDENTIAL_NOT_FOUND` | 404 | Não há credencial para essa combinação de `system_name` e `customer_key`. |
</Accordion>

Se a credencial tiver um certificado digital, o arquivo armazenado é apagado junto.
