Bem-vindo ao guia de primeiros passos da Judit.io! Vamos guiá-lo através dos passos necessários para começar a usar nossa API.

## Adquira Seu Plano

Para começar a usar a Judit.io, você precisará adquirir um de nossos planos. Entre em contato conosco para conhecer nossas opções de planos e escolher o que melhor se adapta às suas necessidades.

## Gere Sua API Key

Após a aquisição do plano, você poderá gerar sua API Key através da nossa dashboard. A API Key é necessária para autenticar suas solicitações à nossa API.

1. Acesse a dashboard da Judit.io.
2. Vá para a seção "API Keys".
3. Clique no botão "Gerar nova API Key".

Lembre-se de manter sua API Key segura. Não a compartilhe publicamente ou com pessoas que não deveriam ter acesso.

## Usando a API Key

Com a API Key gerada, agora você pode começar a fazer solicitações para a API da Judit.io. Para isso, você deverá incluir a API Key no cabeçalho `api-key` das suas solicitações.

## Buscando Seu Primeiro Processo

Para buscar um processo, você deverá fazer uma solicitação GET para a rota `/lawsuits/{processo}`, onde `{processo}` deve ser substituído pelo número do processo que você deseja consultar.

Aqui está um exemplo de como fazer isso usando curl:

```bash
curl -X GET "https://api.judit.io/lawsuits/{processo}" \
-H "api-key: YOUR_API_KEY"
```
