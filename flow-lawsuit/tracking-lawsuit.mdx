<Steps>
  <Step title="Criação do monitoramento" stepNumber="1">
  ```bash
  curl --request POST
    --url "https://tracking.prod.judit.io/tracking"
    --header "api-key: SUA-API-KEY"
    --header "Content-Type: application/json"
    --data "{
      'search': {
      'search_type': 'lawsuit_cnj',
      'search_key': '0817064-37.2023.8.19.0209'
      }
   }"
  ```

   Retorno:
   ```json
   {
   "request_id": "cb97f8ba-7736-43c7-a961-436b151cd65c",
   "search": {
     "search_type": "lawsuit_cnj",
     "search_key": "0817064-37.2023.8.19.0209",
     "response_type": "lawsuit",
     "search_params": {
       "filter": {},
       "pagination": {}
     }
   },
   "origin": "api",
   "origin_id": "ad070209-2523-4808-b2e4-c1571e6fc82b",
   "user_id": "82082593-c664-4d7b-b174-2f0dc4791daf",
   "status": "pending",
   "created_at": "2024-02-21T17:15:02.700Z",
   "updated_at": "2024-02-21T17:15:02.700Z",
   "tags": {}
   }
   ```

  Outros parâmetros que podem ser adicionados na requisição, como
  filtros, podem ser encontrados na página:

  <a href="https://docs.judit.io/api-reference/endpoint/tracking/create">
  https://docs.judit.io/api-reference/endpoint/tracking/create
  </a>

  <Note>
    O monitoramento irá ser iniciado a primeira vez, na melhor janela de
    concorrência de requisição ao tribunal, dentro das próximas 24 horas
    da data de criação.
  </Note>

  Depois ocorrerá todos os dias úteis no mesmo horário.
  </Step>
  <Step title="Consultar o status do monitoramento" stepNumber="2">
  Na URL vai o <strong>tracking_id</strong> retornado na primeira requisição:

   ```bash
   curl --request GET
     --url "https://tracking.prod.judit.io/tracking/cb97f8ba-7736-43c7-a961-436b151cd65c"
     --header "api-key: SUA-API-KEY"
     --header "Content-Type: application/json"
   ```

   Retorno:
   ```json
   {
   "tracking_id": "1b0b88bb-8d7a-4119-a0ef-d863db9c3a94",
   "user_id": "82082593-c664-4d7b-b174-2f0dc4791daf",
   "status": "created",
   "recurrence": 1,
   "search": {
     "search_type": "lawsuit_cnj",
     "search_key": "0817064-37.2023.8.19.0209",
     "response_type": "lawsuit",
     "search_params": {
       "filter": {},
       "pagination": {}
     }
   },
   "tracked_items_count": 0,
   "tracked_items_steps_count": 0,
   "tags": {
     "dashboard_id": null
   },
   "request_id": "ef1ea0fb-cac8-4901-8415-2af08822765b",
   "created_at": "2024-02-21T17:55:22.757Z",
   "updated_at": "2024-02-21T17:55:22.757Z"
   }
   ```

   A propriedade status informa a situação atual do monitoramento,
podendo ser:

 <ol type="a">
   <li>
    <strong>created</strong>: Monitoramento criado, porém nunca executado.
   </li>
   <li>
    <strong>updating</strong>: Está com uma requisição em processamento.
   </li>
   <li>
   <strong>updated</strong>: Monitoramento atualizado já com alguma resposta
   disponível. O campo <u>updated_at</u> pode informar a data de última
   atualização do monitoramento e a propriedade <u>request_id</u> o id
   da última request feita pelo monitoramento.
   </li>
   <li>
    <strong>paused</strong>: Monitoramento pausado, podendo ainda ser reativado.
   </li>
   <li>
    <strong>deleted</strong>: Monitoramento cancelado e não pode mais ser
  reativado.
   </li>
 </ol>

 A propriedade <u>request_id</u> só é criada a partir da primeira vez que o
monitoramento executou, ou seja, chegou ao status updated.
  </Step>
  <Step title="Consultar o conteúdo da resposta" stepNumber="3">
   Na URL vai o <strong>request_id</strong> retornado na primeira requisição:

   ```bash
   curl --request GET "https://requests.prod.judit.io/responses/?request_id=ef1ea0fb-cac8-4901-8415-2af08822765b"
     --header "api-key: SUA-API-KEY"
     --header "Content-Type: application/json"
   ```

    <Note>
    No caso de monitoramento processual a primeira consulta será o
    retorno do processo que pode ser obtido no array <strong>page_data</strong> na
    propriedade <strong>response_data</strong>.
    </Note>

    As demais requisições feitas pelo monitoramento só terão resposta
    caso uma andamento processual novo seja encontrado. O modelo da
    resposta é igual ao da resposta inicial incluindo o(s) andamento(s)
    novos.

   <br />
    O significado de cada campo pode ser encontrado no **[Glossário](/resource/glossary)**
