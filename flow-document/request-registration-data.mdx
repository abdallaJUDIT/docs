 <Step title="Criação de Request" stepNumber="1">
   Para consultar dados cadastrais via CPF ou CNPJ, a requisição deve ser feita utilizando o endpoint `/requests/create` da API de lawsuits.

   **Exemplo de Consulta por CPF:**

   ```bash
   curl --location 'https://lawsuits.prod.judit.io/requests/create' \
    --header 'Content-Type: application/json' \
    --header 'api-key: <API-KEY>' \
    --data '{
        "search": {
            "search_type": "cpf",
            "search_key": "999.999.999-99",
            "response_type": "entity"
	    }
    }'
    ```

    **Exemplo de Consulta por CNPJ:**

    ```bash
   curl --location 'https://lawsuits.prod.judit.io/requests/create' \
    --header 'Content-Type: application/json' \
    --header 'api-key: <API-KEY>' \
    --data '{
        "search": {
            "search_type": "CNPJ",
            "search_key": "99.999.999/9999-99",
            "response_type": "entity"
	    }
    }'
    ```

    <Note>
    Na consulta por dados cadastrais, o search_type deve ser <strong>'CPF'</strong> ou <strong>'CNPJ'</strong>, já o campo response_type deverá sempre ser <strong>'entity'</strong>.
    </Note>
