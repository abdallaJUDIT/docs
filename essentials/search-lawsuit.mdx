A API da Judit.io oferece a possibilidade de buscar processos judiciais usando a rota `/lawsuits/{id}`.

## Rota de Consulta de Processos

Nesta rota pode ser buscado Processos (Código CNJ) ou documentos (CPF ou CNPJ).

Para buscar um processo, você deve realizar uma solicitação GET para a rota `/lawsuits/{id}`, substituindo `{id}` pelo número CNJ do processo desejado.

Para buscar todos os processos de um CPF ou CNPJ, você deve realizar a mesma solicitação acima, substituindo `{id}` pelo número do documento (CPF ou CNPJ).

## Parâmetros de Consulta

A rota de busca de processos também aceita alguns parâmetros de consulta para personalizar a busca:

- `mode`: O parâmetro `mode` é usado especificar o tipo de consulta que você deseja realizar. Ele suporta dois valores: `find` e `crawl`.

  Esse parâmetro só é relevante para quando se está consultando um processo (Código CNJ), para consulta de documentos o comportamento é o mesmo independente do valor desse parâmetro.

  1. `find` - Quando o parâmetro `mode` é definido como `find`, a API irá realizar uma busca pelo processo especificado na base de dados local. Essa operação não envolve nenhuma interação com os tribunais de origem.

     É importante notar que o modo `find` funcionará apenas para os processos que foram previamente acessados usando o modo `crawl`. A informação retornada estará atualizada até a última vez que o processo foi acessado com o modo `crawl`.

     Em resumo, o modo `find` é ideal para recuperar rapidamente as informações dos processos, mas é limitado apenas aos dados que foram coletados anteriormente.

  2. `crawl` - Quando o parâmetro `mode` é definido como `crawl`, a API irá buscar o processo especificado diretamente do tribunal de origem. Isso garante que as informações mais recentes sejam retornadas, refletindo o estado atual do processo.

     O modo `crawl` pode ser mais lento que o `find`, pois envolve a coleta de dados do tribunal de origem. No entanto, ele garante que você tenha as informações atualizadas do processo.

     Em resumo, o modo `crawl` deve ser usado quando você precisa das informações atualizadas ou a primeira vez que consultar um processo.

- `instance`: Este parâmetro permite que você defina a instância em que deseja buscar o processo. O valor padrão é 1, que corresponde à primeira instância.

  Se você quiser buscar o processo na segunda instância, por exemplo, defina este parâmetro como 2.

  Caso o processo consultado de tenha um ou mais processos relacionado em alguma outra instância, esses processos serão retornados em um array de processos relacionados.

- `template`: Esse parâmetro define o tipo de retorno dos dados de um processo. Atualmente estamos trabalhando com o padrão `future`, formato que será compátivel com as próximas versões da API.

Aqui está um exemplo de como usar esses parâmetros de consulta com curl:

```bash
curl -X GET "https://api.judit.io/lawsuits/{id}?mode=crawl&instance=2&template=future" \
-H "api-key: YOUR_API_KEY"
```
