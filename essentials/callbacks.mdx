Quando uma busca ou um monitoramento e feito pela API da JUDIT enviamos um retorno com as informações encontradas. Para que todas as respostas das solicitações sejam enviadas a um único webhook, o cadstro deve ser realizado entrando em contato com nosso suporte: [Judit](https://api.whatsapp.com/send/?phone=5521976748865). Alternativamente, o webhook também pode ser especificado adicionando o parâmetro <strong>callback_url</strong> no payload da requisição, conforme o exemplo abaixo:

```json
{
    "search": {
        "search_type": "lawsuit_cnj",
        "search_key": "9999999-99.9999.9.99.9999"
    },
    "callback_url": "https://webhook.site/b0ac6522-5bfc-42fa-bebf-a8c2b5ec0999",
    "with_attachments": true
}
```

Realizamos uma solicitação POST para o webhook, enviando uma resposta conforme os resultados da sua busca. O retorno ao webhook ocorre assim que o status da requisição é atualizado para **"completed"**.

    "reference_type": "request",
    "reference_id": "6dec567b-c4d7-47cb-ab2c-0393dae9d089",

Exemplos:

O `response_type` tem como valor padrão ***lawsuit***, contudo, esse valor pode ser configurado para outros tipos, conforme necessário. As opções disponíveis são **"steps"**,**"attachments"** ou **"parties"** como mostrado no exemplo abaixo:

```json
{
    "search": {
        "search_type": "lawsuit_cnj",
        "search_key": "9999999-99.9999.9.99.9999",
        "response_type": "steps"
    },
    "with_attachments": true
}
```

Quanto ao retorno no webhook, o `response_type` poderá retornar o valor **"lawsuit"**, **"steps"**,**"attachments"** ou **"parties"**, o campo `response_data` irá gerar as respostas de forma paginada, onde `page_data` será um array que poderá conter no máximo 50 itens e também pode variar seu tipo de acordo com o `search_type` informado.


Se quisermos consultar as respostas para ver um grupo de itens específicos poderemos realizar uma consulta de respostas passando [filtros e paginação](./requests#consultando-respostas-de-buscas).

```json
{
    //...
    "payload": {
         //...
        "response_data": {
          "code": "9999999-99.9999.9.99.9999",
          "instance": 1,
          "page": 1,
          "page_data": PageData[],
          "page_count": 5,
          "all_count": 15,
          "all_pages_count": 3
        }
        //...
    }
}
```

As respostas podem ser enviadas de forma paginada para o webhook configurado. No entanto, ao término do envio completo, uma mensagem de confirmação será enviada, indicando que toda a resposta foram entregues. Essa mensagem final incluirá o statusCode 600 e a mensagem `request_completed`, conforme mostrado abaixo:

```json
{
  "user_id": "7f8065a3-4891-428d-9456-dedfc12ff850",
  "callback_id": "c2c79ac8-8ac7-41fd-a3d5-a4dddb013cfb",
  "event_type": "response_created",
  "reference_type": "request",
  "reference_id": "8ac8f0d0-1372-4281-993b-8b08a521a28a",
  "payload": {
    "request_id": "8ac8f0d0-1372-4281-993b-8b08a521a28a",
    "response_id": "5084577b-075c-48ea-b772-934032a9a7af",
    "origin": "api",
    "origin_id": "8ac8f0d0-1372-4281-993b-8b08a521a28a",
    "request_created_at": "2024-11-14T13:11:22.578Z",
    "response_type": "application_info",
    "response_data": {
      "code": 600,
      "message": "REQUEST_COMPLETED"
    },
    "user_id": "7f8065a3-4891-428d-9456-dedfc12ff850",
    "created_at": "2024-11-14T13:11:57.234Z",
    "tags": {
      "dashboard_id": null
    }
  }
}
```

Caso o processo consultado tenha um ou mais processos relacionado ou em alguma outra instância, esses processos serão retornados em um array `related_lawsuits.
