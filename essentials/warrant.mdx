Esta API permite que partes interessadas verifiquem apenas mandados com o search_type como warrant, garantindo a precisão e a relevância das informações consultadas.


# Exemplo de request de criação de um mandado

Aqui está um exemplo da criação de uma request de mandado por CPF:

```json
{
	"search": {
		"search_type": "cpf",
		"search_key": "60986058319",
		"response_type": "warrant"
	},
	"with_attachments": true
}

```
