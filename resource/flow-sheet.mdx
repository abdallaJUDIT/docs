# 1. ⚖️ Consulta Processual
A propriedade raiz que agrega todos os dados do processo é ``response_data``.

####  🗂️ Capa (Metadados do Processo)

| Variável na Api        | Tipo     | Descrição |
|------------------------|----------|-----------|
| `area`                 | string   | Área do direito conforme classificado no processo (ex: DIREITO ASSISTENCIAL, DIREITO ADMINISTRATIVO, DIREITO AMBIENTAL, etc.) |
| `justice`              | string   | Código do segmento de justiça no padrão CNJ (ex: 4 = Justiça Federal). |
| `tribunal`             | string   | Código numérico do tribunal no padrão CNJ (ex: 04). |
| `name`                 | string   | Nome do processo no formato Parte Ativa X Parte Passiva. |
| `distribution_date`    | string   | Data de distribuição do processo. |
| `instance`             | number   | Grau do processo (instância), representado como number, indicando o nível de jurisdição. |
| `courts`               | array    | Órgão julgador - Refere-se ao órgão ou instituição responsável por administrar a justiça em um processo específico. |
| `secrecy_level`        | number   | Nível de sigilo do processo: 0 = público, 1 = segredo de justiça, 2 = restrito a servidores, 3 = restrito à unidade judicial, 4 = sigiloso para magistrados e chefes de cartório, 5 = sigilo absoluto. |
| `subjects`             | array    | Lista de assuntos do processo conforme tabela oficial de assuntos do CNJ. |
| `classifications`      | array    | Lista de classes processuais conforme tabela oficial de classes do CNJ. |
| `judge`                | string   | Nome do juiz responsável pelo processo. |
| `code`                 | string   | Número único do processo no padrão CNJ (0000000-00.0000.0.00.0000). |
| `justice_description`  | string   | Descrição do segmento da justiça (ex: Justiça Federal, Justiça Estadual, Justiça do Trabalho, etc.). |
| `county`               | string   | Comarca - Uma divisão territorial do sistema judiciário, correspondendo à jurisdição de um juiz de primeira instância. |
| `tribunal_acronym`     | string   | Sigla oficial do tribunal (ex: TRF4, TJSP, TJMG). |
| `city`                 | string   | Indica a cidade relacionada ao registro consultado. |
| `state`                | string   | Indica o estado (Unidade Federativa) relacionado ao registro consultado. |
| `situation`            | string   | Situação processual capturada no tribunal (ex: Em andamento, Suspenso, Arquivado). |
| `phase`                | string   | Fase atual do processo (ex: INICIAL, SENTENÇA, EXECUÇÃO OU CUMPRIMENTO, RECURSO, ARQUIVADO, etc.). |
| `status`               | string   | Status consolidado do processo: ATIVO ou FINALIZADO. |
| `amount`               | number   | Valor da causa em formato numérico, sem formatação monetária. |
| `crawler`              | object   | Refere-se às informações sobre o robô responsável por realizar buscas nos tribunais. |
| `source_name`          | string   | O termo usado para referir-se à fonte em que a pesquisa foi conduzida. *(Geralmente retornado dentro do objeto crawler)* |
| `crawl_id`             | string   | Refere-se ao número de identificação do robô que realiza o processo de busca daquele resultado. *(Geralmente retornado dentro do objeto crawler)* |

#### 👥 `Partes` (parties)

| Variável na Api | Tipo   | Descrição |
|-----------------|--------|-----------|
| `name`          | string | Nome completo da parte conforme consta no tribunal. |
| `main_document` | string | Documento principal da parte (CPF para pessoa física ou CNPJ para pessoa jurídica), retornado apenas com números. |
| `documents`     | array  | Lista de documentos vinculados à parte. Cada item contém: `document_type` (ex: CPF, CNPJ, OAB) e `document` (número sem formatação). |
| `person_type`   | string | Papel processual da parte conforme identificado no tribunal (ex: AUTOR, RÉU, ADVOGADO, PERITO, MINISTÉRIO PÚBLICO, RECORRENTE, RECORRIDO, etc.). |
| `side`          | string | Polo processual da parte: `ACTIVE` (polo ativo), `PASSIVE` (polo passivo), `INTERESTED` (interessado/terceiro) ou `UNKNOWN` (não identificado). |
| `entity_type`   | string | Tipo de entidade da parte: `person` para pessoa física ou `company` para pessoa jurídica. |
| `lawyers`       | array  | Lista de advogados vinculados à parte. Cada item contém `name` e `documents`. Caso o tribunal não vincule o advogado a uma parte específica, ele poderá ser retornado como uma parte independente com `person_type` = ADVOGADO. |

---

#### 🔄  Andamentos (steps)

| Variável na Api     | Tipo    | Descrição |
|---------------------|---------|-----------|
| `lawsuit_cnj`       | string  | Número único do processo no padrão CNJ (0000000-00.0000.0.00.0000). Identificador nacional do processo, utilizado para consulta e correlação entre tribunais e instâncias. |
| `lawsuit_instance`  | number  | Grau do processo (instância) no qual o andamento foi registrado. Representado como `number`, indicando o nível de jurisdição. |
| `step_id`           | string  | Identificador único do andamento dentro do processo. Pode corresponder a um ID interno do tribunal ou a um identificador gerado durante o processamento. |
| `step_date`         | string  | Data e horário oficiais do andamento no formato ISO 8601 em UTC. Representa o momento em que a movimentação foi registrada. |
| `content`           | string  | Texto integral do andamento conforme publicado pelo tribunal. Pode incluir código do movimento e descrição do ato processual. |
| `private`           | boolean | Indica se o andamento está sob sigilo processual. `true` significa que o conteúdo é restrito; `false` indica que a movimentação é pública. |
| `tags`              | object  | Objeto contendo metadados internos associados ao andamento. Pode incluir identificadores técnicos utilizados para rastreamento. |
| `steps_count`       | number  | Quantidade total de andamentos identificados no processo no momento da coleta. |

---

#### 🔄  Última movimentação (last_steps)

| Variável na Api  | Tipo    | Descrição |
|--------------|---------|-----------|
| `step_id`  | string  | Identificação única do andamento. |
| `step_date`  | string  | Data e horário oficiais do andamento. |
| `content`    | string  | Conteúdo/texto descritivo do andamento. |
| `steps_count`    | number  | Quantidade total de movimentações registradas no processo. |

---

#### 📎  Anexos (attachments)

| Variável na Api       | Tipo    | Descrição |
|-------------------|---------|-----------|
| `attachment_id` | string  | Refere-se à identificação única do anexo encontrado no tribunal. |
| `attachment_name` | string  | Título ou nome do arquivo do anexo. |
| `attachment_date` | string  | Data de disponibilização ou registro do anexo. |
| `status`    | string  | Status da captura do anexo (ex: `done` ou `pending`). |
| `step_id`         | string  | ID do andamento processual ao qual o anexo está vinculado. |
| `private`           | boolean | Indica se o anexo está sob sigilo processual. `true` restrito; `false` público. |
| `extension`       | string  | Extensão do arquivo do anexo (ex: PDF, HTML, TXT, etc.). |

# 3. 👮 Mandado de Prisão

#### 🗂️ Capa (Metadados do Processo)

| Variável na Api           | Tipo     | Descrição |
|------------------------|----------|-----------|
| `warrant_type`                 | string   | Tipo do mandado emitido (por exemplo: Mandado de Prisão, Mandado de Recaptura, etc.). |
| `arrest_type`                 | string   | Natureza da ordem de prisão (Ex: `definitive`, `temporary`, `preventive`). |
| `tribunal_id`   | string   | Identificador numérico do tribunal responsável (ID do BNMP). |
| `individual_id`             | string   | Identificador único da pessoa relacionada ao mandado. |
| `number`       | string  | Número interno do mandado no sistema emissor (possui o CNJ). |
| `issue_date`             | string    | Data em que o mandado foi oficialmente expedido no BNMP. |
| `expiration_date`             | string    | Data em que o mandado perde sua validade (se aplicável). |
| `status`     | string    | Status da prisão / situação atual do mandado. |
| `instance`               | number   | Instância judicial responsável pelo processo (Grau). |
| `code`                 | string   | Número único do processo judicial (padrão CNJ) vinculado ao mandado. |
| `tribunal` | string   | Código numérico do tribunal no qual o processo tramita. |
| `justice`              | string   | Código que identifica o ramo da justiça (ex: estadual, federal). |
| `tribunal_acronym`    | string   | Sigla do tribunal (ex: TJSP, TJMG, TJRJ). |
| `court`                | string   | Órgão julgador - Nome da vara, juízo ou departamento onde o processo tramita. |
| `judgementSummary`                | string   | Resumo da decisão judicial relacionada ao mandado. |
| `duration`                | string   | Tempo de pena - Representa a duração total da pena em um único campo. |
| `duration_years`                | number   | Mostra quantos anos fazem parte da pena/mandado. |
| `duration_months`                | number   | Mostra quantos meses fazem parte da pena/mandado. |
| `duration_days`                | number   | Mostra quantos dias fazem parte da pena/mandado. |
| `regime`            | string   | Regime de cumprimento da pena (fechado, semiaberto ou aberto). |
| `recapture`                | boolean   | Indica se o mandado é relacionado à recaptura de uma pessoa evadida (`true` ou `false`). |
| `crawler`              | object   | Refere-se às informações sobre o robô responsável por realizar buscas nos tribunais. |
| `source_name`          | string   | O termo usado para referir-se à fonte em que a pesquisa foi conduzida. *(Geralmente retornado dentro do objeto crawler)* |
| `crawl_id`             | string   | Refere-se ao número de identificação do robô que realiza o processo de busca daquele resultado. *(Geralmente retornado dentro do objeto crawler)* |

#### 👥 `Entity` 
Objeto que representa uma pessoa física, contendo dados de identificação, documentos, vínculos familiares e informações complementares.

| Variável na Api     | Tipo   | Descrição |
|-----------------|--------|-----------|
| `entity_id`          | string | Identificador único interno da entidade (pessoa) no sistema. |
| `name`          | string | Nome completo da parte ou pessoa. |
| `main_document` | string | Documento principal da parte (CPF ou CNPJ), apenas números. |
| `aka_names`          | array | Lista de nomes alternativos, apelidos ou variações do nome da pessoa. |
| `gender`          | string | Gênero informado da pessoa. |
| `birth_date`   | string | Data de nascimento da pessoa. Formato (YYYY-MM-DDTHH:mm:ss.sssZ). |
| `contacts`   | array | Lista de contatos da pessoa, como telefone ou e-mail. |
| `parents`   | array | Array que contém os vínculos parentais da pessoa. |
| `partners`   | array | Lista de cônjuges ou companheiros associados à pessoa. |
| `documents`     | array  | Array de documentos de identificação; cada item contém `document_type` e `document`. |
| `ethnicity`     | string  | Etnia ou cor declarada da pessoa. |
| `nationality`     | string  | Nacionalidade da pessoa. |
| `lawyers`       | array  | Array de advogados vinculados à pessoa. |
| `document_content`       | string  | Conteúdo textual ou estruturado extraído de documentos associados. |
| `warnings_and_determinations`       | string  | Avisos, determinações ou observações judiciais relacionadas à entidade. |
| `observations`       | string  | Observações gerais ou notas adicionais sobre a pessoa. |
| `classifications`       | array  | Lista de classificações ou tipificações associadas à entidade (pessoa). |
| `addresses`       | array  | Array que contém os endereços associados à entidade. |

| Campo | Tipo | Descrição |
|------|------|-----------|
