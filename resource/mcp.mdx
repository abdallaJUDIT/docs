## Como funciona o prompt

O prompt aponta para a [skill da Judit](https://docs.judit.io/skill.md), um roteiro escrito para IAs. Ao ler a skill, a IA:

- **Entende o seu negócio**: pergunta o que você quer resolver, a regra de negócio, o volume e a frequência das consultas.
- **Monta um plano sob medida**: indica os endpoints e filtros mais adequados ao seu caso e o que cada resposta significa para o seu negócio.
- **Usa a documentação sempre atualizada**: consulta só as páginas necessárias, na versão mais recente.
- **Otimiza o uso da API**: escolhe a modalidade e os filtros certos para cada consulta, com mais eficiência e menos retrabalho.
- **Segue as boas práticas**: a `api-key` fica protegida no servidor, e as chamadas assíncronas, webhooks e paginação seguem a doc oficial.
- **Ajuda no dia a dia**: apoia o diagnóstico e prepara um chamado completo para o nosso suporte.

## Instalar o servidor MCP

O servidor MCP da documentação entrega a mesma skill (`judit-api`) e as tools `search_judit_docs` e `query_docs_filesystem_judit_docs`, que a IA usa para buscar e ler a doc sem você copiar e colar.

<Card title="URL do servidor MCP" icon="link" href="https://docs.judit.io/mcp">
  `https://docs.judit.io/mcp`
</Card>

Com o MCP conectado, use este prompt — ele aponta para a skill entregue pelo próprio MCP (recurso `judit-api`), sem depender de acesso à web:

## O que ele não faz

O MCP e o prompt **só leem a documentação**: não chamam a Judit API por você nem geram custo. As chamadas reais são feitas pelo código que a IA escreve, com a sua `api-key` no servidor — ou pela [Postman Collection](/resource/postman-collection).
